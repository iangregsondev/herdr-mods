# worktrunk

## 0.1.0

### Minor Changes

- [#17](https://github.com/iangregsondev/herdr-mods/pull/17) [`5062986`](https://github.com/iangregsondev/herdr-mods/commit/50629868db2f2a7cd9fcac5263bbff3c45bd42eb) Thanks [@iangregsondev](https://github.com/iangregsondev)! - First version of worktrunk (`iangregsondev-worktrunk`): a panel on the right that lists your git repos and their worktrunk (`wt`) worktrees, grouped into Merged, In progress and Conflicts with main. Views for Current, Repos, Clean up, Active, Conflicts and Open, with group chips and search. Row and repo menus merge, remove and clean up worktrees as visible jobs, one at a time. A New or open worktree dialog, a Settings dialog, and five commands you can bind in `keys.json`. Failures (a repo scan, a branch list, an unreadable settings file) show as a banner or toast with the reason instead of an empty list. The menus mod's items reach this panel through a shared mailbox.

- [#87](https://github.com/iangregsondev/herdr-mods/pull/87) [`c7f6691`](https://github.com/iangregsondev/herdr-mods/commit/c7f6691f6735e30b522c3363b19c3db14cf6e3f6) Thanks [@iangregsondev](https://github.com/iangregsondev)! - The panel now closes spaces left on worktrees removed outside it (`wt remove` or `wt merge` in a terminal, an agent's cleanup) when only shells run in them, checked on the space's own machine. A space where anything else runs (an agent, an editor) stays open, and a toast offers to close it once: click it and Herdr asks before closing.

- [#50](https://github.com/iangregsondev/herdr-mods/pull/50) [`e567849`](https://github.com/iangregsondev/herdr-mods/commit/e567849a9a52833e996a11b2ab195b7f36f518a5) Thanks [@iangregsondev](https://github.com/iangregsondev)! - Worktrunk now works across machines. A group folder can name the machine it is on (`~` means that machine's home), and Settings can add one on another machine after checking the path there. Every read and job (scan, `wt list`, CI, Merge, Remove, Clean up, Create) runs on the repo's own machine through its login shell, with one batched read per machine per refresh; a machine still connecting or unreachable gets its own line, and this machine's repos never wait on it. Spaces on every machine count as open, Current follows a space on another machine, and "Open in a new space" opens on the worktree's machine. Two dropdowns pick the machine and the group, and repos show their machine when more than one is in view. A fresh worktree with nothing done in it shows as New, not under Clean up. Status icons explain themselves on hover. Current is first in the view picker, the panel is titled "Worktrunk", failures that used to be silent now show as a toast or banner, and the old `worktrunk.json` is removed once imported.
